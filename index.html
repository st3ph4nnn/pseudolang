Exemplu

            
Programul citește o notă și verifică dacă elevul a promovat.


            
pseudolang

            
foloseste iostream
main
    declara nota int
    citeste nota
    daca nota >= 5 atunci
        afiseaza "Promovat"
    altfel
        afiseaza "Nepromovat"
    sfarsit
incheie


            
C++

            
#include <iostream>

using namespace std;

int main()
{
    int nota;
    cin >> nota;
    if (nota >= 5) {
        cout << "Promovat";
    } else {
        cout << "Nepromovat";
    }
    return 0;
}


            
De reținut

            
    
                
  • Scrie o instrucțiune pe fiecare linie, fără punct și virgulă.
    • 
                
  • Bibliotecile se pun la început, cu foloseste. Poți pune mai multe pe
                    aceeași linie: foloseste iostream string.
    • 
                
  • La declara, tipul se scrie la final: declara varsta int.
                    Poți declara mai multe variabile deodată: declara a b int.
    • 
                
  • Poți declara un vector: declara v[10] int.
    • 
                
  • Condițiile se termină cu atunci, iar blocul se închide cu
                    sfarsit sau gata.
    • 
                
  • La pentru, părțile se despart prin virgule.
    • 
                
  • Programul începe cu main și se termină cu incheie.
    • 
                
  • Pentru indentare folosește Tab și Shift+Tab.
    • 
                
  • Translatorul adaugă automat using namespace std;, deci poți scrie
                    cout și cin direct.
    •

Despre

            

                Pseudolang transformă pseudocodul în C++. Scrii în română, apeși „Evaluează” și
                primești codul C++ în aceeași pagină.
            

            

                Site-ul este făcut pentru orele de informatică și pentru cei care fac primii pași în
                C++. Nu trebuie să instalezi nimic, totul merge direct în browser.
            


            
Cum funcționează

            

                Fiecare linie din caseta de pseudocod este citită separat. Dacă linia începe cu
                „afiseaza”, în C++ apare „cout”, dacă începe cu „daca”, apare „if” și așa mai departe.
            

            

                Restul liniilor sunt transformate la fel, după reguli simple. La final, codul este
                indentat și colorat specific sintaxei pentru lizibilitate.
            


            
Cum se folosește

            

                Alege un exemplu din meniu sau scrie codul tău în caseta din stânga.
            

            

                Apasă „Evaluează”, iar codul C++ apare în dreapta. Cu „Copiază codul” îl poți lua și
                lipi într-un editor C++.
            

            

                Poți schimba oricând exemplul sau poți șterge tot cu butonul „Șterge”.
